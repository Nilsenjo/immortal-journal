# Production preparation results

Nothing was pushed, deployed, published, or changed in DNS during preparation. Existing hosted preview is unchanged. Branding, styles, and messaging were preserved.

## Passed
- Clean npm ci, npm run check, and npm run build. Zero third-party runtime/build dependencies.
- Vercel static output and build commands configured in vercel.json.
- Live hardcover product query: correct product, current USD price, image and availability returned.
- Live Shopify API: create cart, add quantity, remove line, retrieve HTTPS checkout URL. Test carts were left empty; no order placed.
- Chromium desktop 1440×1000, mobile 390×844, and narrow mobile 320×740: no JavaScript page errors or horizontal overflow; live product loaded; add to bag worked; checkout enabled for nonempty bag; remove worked; checkout disabled for empty bag.
- Visual review of full desktop/mobile pages: product imagery, sections, and signup form rendered.
- Opened live Shopify checkout: title “Checkout - Immortal Journal”, checkout fields rendered on immortaljournal.com. No personal/payment information entered and no order submitted.
- Source and tracked Git history scanned for common Shopify, GitHub, artifact, AWS key patterns and private-key headers: zero matches. Not a guarantee against every possible secret format.
- Environment examples contain public settings only; no API token required. Local environment files and Vercel credentials ignored.

## Improvements made for hosting
- Added package metadata, lockfile, build script, Vercel config, security headers, GitHub build-only CI and launch documentation.
- Source moved to public/; dist/ is generated by npm run build.
- Shopify storefront origin is configurable independently of the Vercel website, preventing newsletter submission to a Vercel page after the domain switch.
- Restricted checkout redirects to configured Shopify hosts.
- Prevented unavailable sessionStorage from making purchasing fail in restricted browsers.
- Disabled checkout while cart removal is in progress.

- Add shop.immortaljournal.com to Shopify, make it the Shopify Online Store primary domain, verify TLS, then configure SHOPIFY_STOREFRONT_URL and retest. No domain setup has been performed.
- Newsletter uses Shopify native customer form; real signup persistence and any double-opt-in flow must be confirmed with a consenting address in Shopify Customers. Prior automated submission encountered Shopify's verification challenge. No subscriber was created during this preparation.
- Completed payment, shipping rates, taxes, policies and Shopify-to-Printify fulfillment must be verified by merchant test order before launch. Cart tests do not prove order fulfillment.
- Chromium emulation is not a physical iPhone/Android or Safari test. Check the Vercel preview on your own phone too.
- Current API version 2026-07 must be reviewed before Shopify retires it.

## Browser environment note
The initial browser failed external requests because Chromium lacked trust for the managed environment's proxy CA. Tests were rerun successfully with the configured CA trusted in an isolated workspace browser profile. TLS verification was not disabled. That certificate/profile is not part of the website or deployment package.
